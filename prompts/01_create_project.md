# Prompt 01 - Create project skeleton

Create the Spring Boot Maven project skeleton for the INQCUST Customer Inquiry API.

Use:
- Java 21
- Spring Boot 3
- Maven
- package: `com.fdm.bankofz.customerinquiry`

Dependencies:
- spring-boot-starter-web
- spring-boot-starter-validation
- spring-boot-starter-actuator
- springdoc-openapi-starter-webmvc-ui
- spring-boot-starter-test

Create package structure exactly as defined in `docs/spec.md`.

Do not implement business logic yet. Create empty classes/interfaces with TODO comments matching the spec.
