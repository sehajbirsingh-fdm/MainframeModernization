## Findings

### BLOCKER-001: UPDCUST update route appears unprotected due security matcher/path mismatch

- Evidence: `UpdateCustomerController` maps `/api/v1/customers` and `PUT /{customerNumber}` at `backend/api/src/main/java/com/bankofz/mainframemodernization/updcust/controller/UpdateCustomerController.java:19` and `backend/api/src/main/java/com/bankofz/mainframemodernization/updcust/controller/UpdateCustomerController.java:28`. Security chain matches only `/v1/accounts/**` and `/v1/customers/**` at `backend/api/src/main/java/com/bankofz/mainframemodernization/inqacc/config/InqaccSecurityConfiguration.java:27`.
- Why it matters: The changed write endpoint may bypass configured authentication/authorization policy, which is merge-blocking in the API/security profile.
- Suggested fix: Align matcher patterns to actual API prefix (`/api/v1/**`) and add explicit authorization rules for `PUT /api/v1/customers/**`; add 401/403 controller tests.
- Recommended owner: Security
