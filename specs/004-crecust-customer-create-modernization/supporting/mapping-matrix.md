# Mapping Matrix for CRECUST Modernization

**Document ID:** `mapping-matrix.md`

## 1. Legacy Artifact to Modern Component Mapping

| Legacy Artifact | Modern Component | Responsibility |
|---|---|---|
| `CRECUST.cbl` | `CustomerCreateService` | Orchestrates create flow and rule sequencing |
| `CRECUST.cpy` | `CreateCustomerRequest` / `CreateCustomerResponse` | Request/response transport model |
| `CUSTOMER.cpy` | `CustomerRecord` domain model | Canonical persisted customer fields |
| `CUSTDB2.cpy` | Repository schema contract | Persistence column shape and constraints |
| `CUSTCTRL.cpy` + CONTROL semantics | `CustomerControlRepository` | Next customer-number generation |
| `NEWCUSNO.cpy` intent | `CustomerNumberAllocator` | Counter function abstraction |

## 2. Field-Level Mapping

| COMMAREA Field | CUSTOMER/DB Field | API Field | Notes |
|---|---|---|---|
| `COMM-EYECATCHER` | `CUSTOMER_EYECATCHER` | `eyecatcher` | Always `CUST` on success |
| `COMM-SORTCODE` | `CUSTOMER_SORTCODE` | `sortCode` | System-derived |
| `COMM-NUMBER` | `CUSTOMER_NUMBER` | `customerNumber` | Generated by control increment |
| `COMM-TITLE` | `CUSTOMER_TITLE` | `title` | Allowlist validated |
| `COMM-FIRST-NAME` | `CUSTOMER_FIRST_NAME` | `firstName` | Trim output |
| `COMM-LAST-NAME` | `CUSTOMER_LAST_NAME` | `lastName` | Trim output |
| `COMM-DOB day/month/year` | `CUSTOMER_DATE_OF_BIRTH` | `dateOfBirth` | Stored integer `YYYYMMDD`, returned ISO date |
| `COMM-CREATED-DATE day/month/year` | `CUSTOMER_CREATED_DATE` | `createdDate` | Request carries day/month/year; stored integer `YYYYMMDD`, returned ISO date |
| `COMM-PHONE` | `CUSTOMER_PHONE` | `phone` | Trim output |
| `COMM-ADDR-LINE1` | `CUSTOMER_ADDR_LINE1` | `addressLine1` | Trim output |
| `COMM-ADDR-LINE2` | `CUSTOMER_ADDR_LINE2` | `addressLine2` | Trim output |
| `COMM-CITY` | `CUSTOMER_CITY` | `city` | Trim output |
| `COMM-POSTCODE` | `CUSTOMER_POSTCODE` | `postcode` | Trim output |
| `COMM-COUNTRY` | `CUSTOMER_COUNTRY` | `country` | Trim output |
| `COMM-STATUS` | `CUSTOMER_STATUS` | `status` | Passed through as 10-char field in parity mode |
| `COMM-CREDIT-SCORE` | `CUSTOMER_CREDIT_SCORE` | `creditScore` | Averaged or fallback 0 |
| `COMM-CS-REVIEW-DATE` | `CUSTOMER_CS_REVIEW_DATE` | `creditScoreReviewDate` | Stored integer, returned ISO date |
| `COMM-SUCCESS` | N/A | `legacyStatus.commSuccess` | `Y` or `N` |
| `COMM-FAIL-CODE` | N/A | `legacyStatus.commFailCode` | Legacy diagnostics |
