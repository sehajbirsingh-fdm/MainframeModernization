# Field Mapping Matrix - INQTRANL

This matrix traces legacy INQTRANL data flow from COMMAREA inputs/controls through host variables, DB2 usage, working-storage transformations, and COMMAREA outputs, with provisional target concepts kept explicitly non-final.

Classification labels:
- Confirmed Mapping
- Reasonable Inference
- Provisional Target Mapping
- Remaining Uncertainty

Label usage note:
- `Confirmed Mapping` applies to verified legacy data flow and behavior.
- `Provisional Target Mapping` applies only to future modernization concepts, not final contract decisions.
- `Remaining Uncertainty` marks behavior not provable from supplied legacy artifacts.
